# TravelRadar V1

Mobile-first MVP for testing the core TravelRadar flow.

## Run
Open `index.html` in a browser, or publish the folder with GitHub Pages.

## V1 flow
Add Reel URL → save current location → view nearby places → filter by category → adjust radius → open Reel.

The app stores demo/saved places in localStorage. Geolocation requires HTTPS (GitHub Pages provides this).
